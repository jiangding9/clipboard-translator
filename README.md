# 剪贴板翻译工具 📋→🇨🇳

复制任意语言的文本，自动翻译成中文并在屏幕右下角弹窗显示。无需切换窗口，复制即翻译。

## ✨ 特点

- **复制即翻译**：复制外文文本，右下角自动弹出中文译文
- **自动识别语言**：任意语言自动翻译成中文，已经是中文的内容自动跳过
- **零配置**：无需 API key，下载即用
- **免安装**：单个 exe 文件，双击运行，无需安装 Python 或任何依赖

## 🚀 使用方法（普通用户）

1. 到 [Releases](../../releases) 页面下载 `剪贴板翻译工具.exe`
2. **双击运行**
3. 启动后，屏幕右下角会弹出一个 **“✅ 已启动”** 的提示，表示程序正在后台运行
4. 现在去任何地方复制一段外文（网页、文档、聊天等），右下角就会自动弹出中文译文

> **退出程序**：在任务管理器中结束 `剪贴板翻译工具` 进程即可。

### ⚠️ 重要说明：双击后“没有窗口”是正常的

本工具是**后台运行**的，双击后不会打开任何主界面。除了启动时那个短暂的“已启动”提示，平时它就安静地待在后台。**你只需要复制外文文本，译文就会自动弹出来。** 这不是故障。

## ❓ 常见问题

**双击后好像没反应？**
程序在后台运行，没有主窗口。留意屏幕右下角的“✅ 已启动”提示。之后复制任意外文即可看到译文。

**首次启动有点慢？**
单文件 exe 首次运行需要自解压，等几秒即可，属正常现象。

**Windows Defender / 杀毒软件报毒或拦截？**
这是 PyInstaller 打包的 exe 的常见**误报**（因为采用“自解压运行”的方式），并非真的有病毒。本项目代码完全开源，你可以自行查看。遇到拦截时选择“仍要运行”或添加信任即可。介意的话也可以按下方“从源码运行”自行构建。

**复制中文没反应？**
这是设计如此——已经是中文的内容不需要翻译，会自动跳过。

**翻译失败？**
本工具使用免费在线翻译接口，需要联网。网络不通或请求过于频繁时可能失败，弹窗会显示 `[翻译失败]`。

## 🛠️ 从源码运行 / 自行构建（开发者）

需要 Python 3.8+。

```bash
# 安装依赖
pip install -r requirements.txt

# 直接运行
python main.py

# 或自行打包成 exe
pip install pyinstaller
pyinstaller --onefile --noconsole --name "剪贴板翻译工具" --collect-all deep_translator main.py
# 生成的 exe 在 dist/ 目录下
```

## ⚙️ 自定义配置

打开 `main.py` 顶部的配置区可调整：

| 配置项 | 说明 |
|--------|------|
| `TARGET_LANG` | 目标语言，默认 `zh-CN`（简体中文）。改成 `en` 即翻译成英文 |
| `POLL_INTERVAL_MS` | 剪贴板检查频率（毫秒），默认 600 |
| `POPUP_TIMEOUT_MS` | 弹窗自动消失时间（毫秒），默认 8000 |
| `POPUP_WIDTH` | 弹窗宽度（像素），默认 420 |

## 📦 技术栈
